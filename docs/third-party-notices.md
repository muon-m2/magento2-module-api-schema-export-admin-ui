## Tabler Icons

The MUON hub menu icon in `view/adminhtml/web/css/admin-menu.css` is a Tabler Icons glyph,
embedded as an inline SVG data URI and redrawn at a heavier stroke (2.4 rather than Tabler's stock
2, so it does not read lighter than Magento's own solid-fill menu glyphs).
